## 1. Abhishek baseline (positioning)

| Dimension | What the page says today |
|-----------|---------------------------|
| **Primary offer** | Portfolio of **11s performance ads** (8–15s hooks, 9:16), **OTT-style films/series**, demos & brand work — **AI-assisted pipelines + human QC** |
| **Tools named** | Veo / Flow, CapCut, Kling, ElevenLabs |

| **Categories** | Filters: **11s Ads**, **Films & OTT**, **Other Work** (product demo / engineering credibility) |
| **CTA** | LinkedIn, GitHub, Upwork intro — no pricing, packages, or “book a call” |
| **Canonical URL** | `videoads.abhishekjha.com` (already in HTML `canonical` + footer) |

### Gaps vs typical agencies / AI ad shops

| Typical competitor | Abhishek page today |
|--------------------|---------------------|
| Retainers, $/video, or % of spend | No commercial packaging |
| ROAS / CPA case studies | Playlist links; light outcome metrics |
| “Unlimited ads / week” velocity claims | Spec + placeholder slot (“spec ad — slot 2”) |
| UGC creator network or marketplace | AI avatar + spec cuts only |
| Media buying + creative under one roof | Creative portfolio only |
| **Differentiator to lean into** | **Rare combo:** cinematic/OTT (Dracula Hunters, brand film) **plus** hook-length paid social **plus** **agent/engineering** credibility (LightningGen, GitHub) |

## 4. Domain recommendations (aligned with project preference)

**Default (unchanged):** keep **`https://videoads.abhishekjha.com`** as the single canonical portfolio URL — consolidates Person ↔ Work for SEO, AEO, LinkedIn/Upwork DMs ([video-portfolio-domain.md](./video-portfolio-domain.md)).

### Subdomain on `abhishekjha.com` (recommended family)

| Idea | Pros | Cons |
|------|------|------|
| **`videoads.abhishekjha.com`** *(chosen)* | Exact intent; matches page title; good for “AI video ads” queries tied to your name | Slightly narrow if OTT/film becomes primary story |
| **`motion.abhishekjha.com`** | Broader than ads; aligns with studio competitors (`.studio` crowd) | Weaker keyword match for performance buyers |
| **`film.abhishekjha.com`** or **`watch.abhishekjha.com`** | Elevates OTT/series (Dracula, brand films) | Underplays 11s / paid social hook |
| **`reels.abhishekjha.com`** | Clear 9:16 / Shorts signal | Sounds consumer-creator, less “agency cred” |
| **`work.abhishekjha.com`** | Neutral portfolio hub | Vague in DMs (“see my work”) |

### Standalone names (only if spinning a **separate agency/product** later)

| Idea | Pros | Cons |
|------|------|------|
| **`11s.studio`** / **`elevensecond.studio`** | Memorable, ownable; matches Chroma/11s niche | New domain authority; disconnect from **Abhishek Jha** unless heavily cross-linked |
| **`hookcut.studio`** | Speaks performance editing culture | Not obviously AI/film |
| **`chromacut.com`** | Ties to Chroma Awards category | Narrow; trademark/category confusion risk |
| **`agentfilm.ai`** | Highlights **agent engineering + film** differentiator | `.ai` saturation; still need personal bridge |

## 5. What to emphasize on the page (credibility in this landscape)

**Homepage trust row (competitors lead with this on page 1):** speed in **days** (Ad Lantern 1–3d, EditClub 48h, AdVido ~3d) · **revisions** · **you own files / IP** · **cost vs traditional agency** · **native/not AI-slop** (EditClub FAQ). Abhishek doc: [11s-site-value-props-no-roas.md](./11s-site-value-props-no-roas.md) § Trust strip.

1. **Human-directed AI, not tool demos** — Mirror AdVido/EditClub/Rowads: name the pipeline (brief → hook variants → QC) and **delivery format** (9:16 MP4, captions, platform-safe length).
2. **Two proof lanes in one URL** — **Performance** (11s playlists, vertical specs) **and** **narrative** (Contra series, brand film) — most direct comps pick only one.
3. **Engineering trust** — Keep **LightningGen / GitHub** visible; differentiates from pure avatar SaaS (Arcads/HeyGen) and from faceless Upwork volume shops.
4. **Explicit scope line** — e.g. “Portfolio & select client work — not a self-serve generator” to set expectations vs Creatify/Tagshop.
5. **One measurable line per category** when possible (views, festival, client vertical) — adjacent agencies win on **numbers** (UGC Factory, Shook case studies).
