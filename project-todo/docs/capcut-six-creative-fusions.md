# Six CCW entries — max-creative fusion briefs

**Canonical stories (latest):** [capcut-six-canonical-briefs.md](/cursor/stores/self/docs/capcut-six-canonical-briefs.md) — **use this for production.**

**Use with:** [multi-submission plan](/cursor/stores/self/docs/capcut-multi-submission-plan.md) · [asset pack](/cursor/stores/self/docs/capcut-world-asset-pack.md) · **No monitor/phone portal** on **#1, #2, #4–#6** — **#3** optional short projection after hack.

Each entry is a **different “wildest arrival”** optimized for judges: **Creativity · Storytelling · Visual excellence · Popularity**.  
**One Contra submission = one finished video (15–60s)** — a **single continuous story**, not several unrelated clips stitched together.

### Production model (Seedance + CapCut)

| Rule | Practice |
|------|----------|
| **Length** | **35–50s** one timeline per entry (inside **15–60s** rules). |
| **Seedance** | Prefer **one long generation** (or 2–3 **matched** extensions) with a **scene bible** so character/wardrobe stay consistent. |
| **Many scripts in docs** | **Alternate takes** — generate variants, **pick one hero** per SKU; workflow on Contra describes what you **chose**, not every failed gen. |
| **CapCut** | Grade, SFX, titles, **WELCOME TO CCW** skill, final export + **project link** from that **one** master cut. |

**Tropes can mix across the six separate entries** — not inside one file.

## 1 · Dracula Hunters — **Kalu Dragon Drop-Off** (LOCKED IP · one continuous video)

**Fusion:** One **Seedance-long** gothic action → comedy arrival — **no mirror**; **no** generic float-to-LA (dragon is **character transport**, Dracula **chooses** to drop you at CCW).

| Beat (single arc) | Creative move |
|-------------------|----------------|
| **Awaken** | Hunter wakes in crypt/desk; **CCW invite** parchment or fang ticket — wrong era, right event. |
| **Fight** | Short beat vs **Dracula** (silhouette/stylized, no gore bath). |
| **Ride** | **Kalu dragon** — hunter mounts; **aerial** travel reads as **partner ride**, not paper-plane gag. |
| **Drop-off** | Dracula (alive, petty) **points down** — dragon **lands at CCW** (`capella-*` / **WELCOME TO CCW** + recap slice). |
| **Tag** | Hunter steps off; `#1000WaysToCCW` · “Even Dracula had directions.” |

**Seedance:** Lock **hunter + dragon scale pattern** in scene bible; extend once for **landing** if needed.

**Judge fit:** **Storytelling 10** if arc is clear in one pass; **Creativity** from villain uber to a creator con.

## How to raise low scores → high (action playbook)

Judges score **Creativity · Storytelling · Visual excellence · Popularity**. The table below maps **weak dimensions** to **concrete CapCut moves** (not more ideas — **better execution**).

### Universal levers (any entry)

| Lever | Low score symptom | Raise it by |
|-------|-------------------|-------------|
| **Visual** | Flat, stock look | One **LUT** across all clips; **9:16** subject in upper third; **one** hero color (teal CCW or gothic amber) |
| **Complexity** | Feels like 1–2 prompts | **8+ documented shots** in workflow; **match cuts** on eye/blink/wheel; name each prompt in Contra paste |
| **Creative depth** | Generic arrival | **One sentence premise** on screen in first 3s; subvert a crowded trope (you already avoid monitor/genie) |
| **SFX** | Music only | **3-layer audio:** bed + **whoosh/hit** on every cut + **1s silence** before final reveal |
| **VFX** | Hard cuts between worlds | **Transition spine:** particles, speed ramp, or **whip pan** — never raw jump between gens |
| **Popularity** | Late post | Social **24h before** deadline; caption = premise + hashtags; **30s BTS** separate post |
