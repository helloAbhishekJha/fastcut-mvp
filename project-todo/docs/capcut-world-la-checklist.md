## Official rules (study notes)

**Theme:** Step into the world you create. **AI is your ticket** if you’re not flying to LA.

**#1000WaysToCCW brief:** 15–60s **fun, engaging** video in **CapCut Video Studio**. Teleport, portal, crash-land, walk out of a movie — **the more unexpected, the better.**

**Fast path (allowed):** Web CapCut → **Skills** (next to + / Auto) → event **“WELCOME TO CCW”** card → import clips → auto edits/transitions/music. You can still customize on top.

**How to participate**

1. **Join Challenge** on Contra (this topic).
2. Apply for **8,000 credits** (1–2 working days).
3. Edit in **CapCut Video Studio** (web or desktop).
4. **Social post** (required for prize pool): IG / X / TikTok / LinkedIn with **`#CapCutWorld`** **`#CapCutWorldLA`** · tag **@capcutapp** (IG) or **@CapCut** (TikTok/X/YT).
5. **Contra submit:** final video + **CapCut project link** + **social post link** + **prompt/workflow breakdown**.

**Submission requirements**

| Rule | Detail |
|------|--------|
| **Original** | Your work, created **Oct 16–26, 2026** |
| **Tool** | Made in **CapCut**; keep proof (screenshots / screen recordings) — winners may verify |
| **Length** | **15–60s** AI/creative video |
| **Package** | Video + project link + workflow breakdown + **[must] social post link** |

**How judges score you (optimize the edit for these four)**

| Criterion | What to nail in *your* entry |
|-------------|------------------------------|
| **Creativity** | Absurd arrival (DH portal), not a travel vlog |
| **Storytelling** | Clear arc: stuck in the “wrong world” → **physical** impossible transit → **on stage at CCW** (no monitor-as-portal) |
| **Visual excellence** | Cinematic grade, consistent character, one polished portal/VFX beat |
| **Popularity** | Strong social post + engagement (views/likes/shares) — post early |

**Social post (required — separate from hero cut)**

Great posts often include:

- **30+ second walkthrough** (Loom or screen recording of CapCut timeline)
- BTS / process shots
- 1–2 sentences: concept + how you built it
- Tags: **@CapCut** · **#CapCutWorld** · **#CapCutWorldLA**

Guidelines cite past examples: Javier, Charlota, Fernanda (on Contra guidelines page).

**Credits usage (recommended):**

1. Use **challenge credits first** for anything that must read as “made in CapCut” (Skills card, light t2v, titles FX, one portal polish).
2. Do **not** burn 8k — entry needs a coherent **15–60s** piece + **project link**, not max gens.
3. Pre-cut hero beats in timeline from **existing Veo/DH footage**; reserve credits for **WELCOME TO CCW** skill + 1–2 CapCut-only fixes (portal glow, lip sync if needed).
4. If a gen fails, duplicate timeline branch before retrying (keep workflow proof).

## Export specs

| Field | Spec |
|-------|------|
| **Length** | **15–60 seconds** (aim **30–45s** for punch + rewatch) |
| **Aspect** | **9:16** primary (Reels / TikTok / Shorts); optional **1:1** or **16:9** export for LinkedIn/X if you crop in CapCut |
| **Resolution** | **1080×1920** minimum |
| **Frame rate** | Match timeline (24 or 30 fps — stay consistent) |
| **Codec** | H.264 or H.265, high quality; **no** invideo-only export as final — finish in **CapCut Video Studio** |
| **Audio** | Mixed VO + music; normalize peaks; royalty-safe music from CapCut library or licensed |
| **Created window** | Original work **Oct 16–26, 2026** (challenge period) |
| **Filename** | `capcut-world-la-dh-arrival-YYYYMMDD.mp4` |

Keep the **CapCut project** shareable (link for Contra) — do not delete until after judging.
