## Do today (priority order)

1. **Do not share** any OTP with anyone; ignore links in SMS unless you started the login yourself.
2. **Call your mobile operator** (Airtel/Jio/Vi/etc.) from **another phone** if possible:
   - Ask: any **SIM swap**, duplicate SIM, or **eSIM** activation on your number in the last **7–14 days**
   - Request **reversal/block** if unauthorized; ask for **transaction/SIM change log**
3. **Check phone behavior:** sudden **no signal**, **2G only**, or “SIM not registered” = classic swap sign — operator call **immediately**.
4. **On each service** (only if you ever used them): log in via **official app/site** (not SMS links) · review **recent logins** · change password · enable **2FA with app**, not SMS where possible.
5. **If you never signed up:** likely **wrong-number OTP noise** — still do **operator SIM check** once; optionally ignore repeat OTPs after 24h if signal is normal.
6. **Bank / UPI / email:** if SIM was swapped, assume **SMS 2FA at risk** — check bank SMS alerts, UPI devices, Gmail “recent security activity”.
7. **India:** note time of OTPs; if operator confirms fraud, ask their **fraud helpline** and consider **cybercrime.gov.in** if money/account access involved.
