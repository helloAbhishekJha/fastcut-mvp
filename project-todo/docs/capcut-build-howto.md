## Phase 3 — Build Entry #1 on the timeline (order matters)

### 3.1 Rough story cut (no effects yet)

| Order | Target time | Clip | CapCut action |
|-------|-------------|------|----------------|
| 1 | 0:00–0:03 | Hunter wake / eyes / candle | Hard cut in; trim to 3s |
| 2 | 0:03–0:12 | Fight vs Dracula | 2–3 cuts max; keep readable |
| 3 | 0:12–0:16 | **Eagle + CCW ticket** | Eagle pass or ticket drop; **freeze 0.5s** on ticket |
| 4 | 0:16–0:18 | Both pause | Reaction shots or hold |
| 5 | 0:18–0:28 | Mount **Kalu** + flight | One continuous feel; speed ramp optional |
| 6 | 0:28–0:38 | Land CCW + Dracula wave | Plate from `refs/` + hunter step-off |
| 7 | 0:38–0:42 | Tag | Titles (below) |

**Total:** ~40s (stay **15–60s**).

### 3.2 WELCOME TO CCW skill (required beat)

| Step | Action |
|------|--------|
| 3.2a | Creation bar → **Skills** (near + / Auto) → **“WELCOME TO CCW”** event card. |
| 3.2b | Import your **DH + crowd** clips as skill suggests; generate. |
| 3.2c | Trim **best 4–6s** into timeline at **landing** (replace or blend with raw plate). |
| 3.2d | Keep skill output in project — judges want **CapCut-native** proof. |

### 3.3 Polish (visual excellence)

| Step | Action |
|------|--------|
| 3.3a | **One LUT / adjust** on all clips (gothic amber → CCW teal on arrival). |
| 3.3b | **Titles:** 0:02 *Wrong century. Right stage.* · end `#1000WaysToCCW` + `#CapCutWorld` `#CapCutWorldLA` |
| 3.3c | **Transitions:** whip or particle **only** at eagle beat and landing (no random jumps). |
| 3.3d | Optional: 1 CapCut AI touch (dragon glow / ticket shimmer) — **log prompt** for Contra. |

### 3.4 Audio (SFX layer)

| Time | Sound |
|------|--------|
| 0:00 | Sting + low drone |
| Fight | Hits, cape whoosh |
| Eagle | Wing flap + **paper rustle** on ticket |
| Pause | Brief **silence** (~0.3s) |
| Flight | Wind bed |
| Land | Crowd cheer (library) + music drop |
| End | Music tail |

Normalize peaks; duck music under SFX on eagle crack moment.

## Common mistakes

- Using **phone/laptop portal** in story (#3 only: short venue projection).  
- **60s of unrelated** best clips — one arc only.  
- Forgetting **social URL** on Contra (most common miss).  
- Export from mobile app only — finish in **Video Studio** for project link.
