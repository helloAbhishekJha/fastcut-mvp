# CapCut World LA — six canonical briefs (one video each)

**Deadline:** Mon **Oct 27, 2026 ~12:29 PM IST** · [#1000WaysToCCW](https://contra.com/community/topic/capcutworldlachallenge/guidelines)  
**Rules:** **15–60s** · **one continuous video** per Contra entry · CapCut Video Studio finish + project link + workflow + social URL.

**Production:** **Seedance** long / matched extends for consistency; other prompts in docs = **alternate takes**, pick **one hero** per SKU.
