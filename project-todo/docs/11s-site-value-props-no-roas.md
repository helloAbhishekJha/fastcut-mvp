## Platform-based ad recommendations (each platform is different)

Use as **Tier B** on site or a one-page brief. Wording: **“what we recommend for this platform”** — not guaranteed sales or rank.

**Rule:** Do **not** ship the same MP4 to **Amazon, Etsy, and Instagram** — specs, tone, and length differ.

### Instagram (Reels · Feed · Stories ads)

| | Recommendation |
|--|----------------|
| **Goal** | Stop scroll, **brand feel**, retargeting |
| **Ad types** | **8–15s hook** (problem → product), **UGC-native 9:16**, cinematic product hero, **carousel → Reel** cutdown |
| **Not** | Long listing-style VO, white-background catalog only |
| **Research** | Top Reels in niche, hook patterns, caption themes |

### Amazon (+ Flipkart-style listing video)

| | Recommendation |
|--|----------------|
| **Goal** | **Listing conversion**, feature clarity, trust |
| **Ad types** | **30–90s listing master** (features, scale, use cases), **silent/light VO**, on-screen callouts; **Sponsored Brand / video ad** cuts **15–30s** from master |
| **Not** | Pure meme hooks, heavy trend audio |
| **Research** | Competitor A+ content, review pain points (“size”, “drape”, “material”) |
| **Pair** | **Brand avatar** for **challenging categories** (e.g. saree **3-angle drape**) without full studio shoot |

### Etsy (and handmade / creator marketplaces)

| | Recommendation |
|--|----------------|
| **Goal** | **Maker story**, materials, process, giftability |
| **Ad types** | **15–45s** “made for you” story, **hands + product** (or avatar for **challenging** wear shots), **seasonal shop** promos, **Pinterest-vertical** friendly cuts |
| **Not** | Aggressive DTC discount spam, Amazon-style spec sheet only |
| **Research** | Best-selling listings in category, shop video on listings, Etsy search phrases |

### Other surfaces (quick ref)

| Surface | Different because… | Typical ad / video |
|---------|-------------------|-------------------|
| **YouTube Shorts** | Discovery + search intent | **15–35s** how-to / myth-bust, clear title card |
| **Meesho / social commerce** | Price + regional trust | **15–30s**, Hindi/Bengali, value hook |
| **WhatsApp / catalog** | Direct share, low attention | **11–20s**, one hero + 3 bullets |
| **Brand site / Meta ads** | Full story + retarget | **30–60s** hero + **11s** hook variants |

**Research inputs (defensible):** public competitor ads/listings, review themes, hashtag/listing patterns — **not** private sales data you don’t have.

**Tracking:** Tier B Book → `?from=platform-ads` (alias `format-research` OK in analytics).

## Brand avatars — challenging categories (e.g. saree modeling)

**Positioning:** Not “cheap fake influencer” — **consistent, on-brand presenter or model substitute** for **challenging categories** where:

- Live shoots are **expensive, slow, or hard to repeat**
- **Drape / fit / styling** needs repeatable angles (e.g. saree)
- Marketplaces need **clear product visibility**

**On site:** Show **before/after** or **3-angle drape** reel; state **AI-assisted + human QC** where platforms require disclosure.

**Human judgment:** High **like** from ethnic wear / jewelry / wellness DTC; low from buyers who only want real UGC creators — **that’s the filter you want**.

## Discovery plan (Book button tests)

1. Ship **four Tier A** Books + **one Tier B** Book (`platform-ads`).  
2. After **~2 weeks** / **~50 visits**, rank clicks; **promote top 2** above fold; demote rest.  
3. If **`brand-avatar`** wins, add **saree/ethnic case card** only — don’t dilute with unrelated niches.  
4. If **`platform-ads`** wins, productize a **paid platform ad brief** (Amazon / Etsy / Insta pack); if **`own-ip`** wins, lead Films tab.
